## 📦 Migration from this repository

If you are already using this repository, follow these steps:

### 1. Update package.json

Change your dependency from:
```json
{
  "dependencies": {
    "notsobot-tagscript-include": "^2.0.0"
  }
}
```

To:
```json
{
  "dependencies": {
    "notsobot-tagscript-preprocessor-utils": "^2.0.0"
  }
}
```

### 2. Reinstall dependencies

```bash
npm install
```

### 3. Update CLI command (if applicable)

**Old:**
```bash
npx nsb-i <file> [options]
```

**New:**
```bash
npx nsb-p <file> [options]
```
